====================================================================
LANGSMITH vs DEEPEVAL
INTERVIEW NOTES FOR AI ENGINEERS
====================================================================

Author Notes:
These notes summarize when to use DeepEval and LangSmith,
their differences, cost considerations, architecture usage,
and common interview questions.

====================================================================
1. ONE-LINE DIFFERENCE
====================================================================

DeepEval:
    Evaluation Framework

LangSmith:
    Observability + Tracing + Monitoring + Evaluation Platform

Simple Memory Trick:

DeepEval tells you:
    "HOW GOOD is my AI application?"

LangSmith tells you:
    "WHY is my AI application behaving this way?"


====================================================================
2. PRIMARY PURPOSE
====================================================================

DEEPEVAL
---------

Used to measure quality.

Examples:

- Faithfulness
- Answer Relevance
- Contextual Recall
- Contextual Precision
- Correctness
- Toxicity
- Bias
- Safety Testing
- RAG Evaluation
- Agent Evaluation

Goal:

Quantify quality using scores.


LANGSMITH
---------

Used to observe and debug applications.

Examples:

- Tracing
- Prompt inspection
- Tool-call inspection
- Agent step visualization
- Dataset management				------check this why
- Experiment tracking
- Online monitoring
- User feedback analysis

Goal:

Understand application behavior.

13. INTERVIEW QUESTIONS & ANSWERS
====================================================================

Q1. Difference between LangSmith and DeepEval?

Answer:

DeepEval is primarily an evaluation framework used to
measure quality metrics such as Faithfulness,
Answer Relevance, Correctness, and RAG metrics.

LangSmith is an observability platform used for tracing,
monitoring, debugging, and analyzing LLM applications.

DeepEval tells us how good the system is.

LangSmith tells us why the system behaves that way.


Q2. Is DeepEval free?

Answer:

DeepEval is open source and free.

The actual cost comes from the Judge Model being used,
for example GPT-4o or GPT-4o-mini.


Q3. Is LangSmith free?

Answer:

LangSmith provides a free tier.

Large-scale enterprise usage generally requires paid plans.


Q4. Should DeepEval run for every production request?

Answer:

No.

Running DeepEval on every request increases:

- Cost
- Latency
- Complexity

Instead, run evaluations periodically on sampled
production data.


Q5. Which tool is used most during development?

Answer:

LangSmith for debugging and tracing.

DeepEval for quality measurement.


Q6. Which tool is more important for interviews?

Answer:

DeepEval.

Most AI Engineer interviews focus on:

- Faithfulness
- Answer Relevance
- Correctness
- RAG Triad
- Evaluation Pipelines

which are DeepEval concepts.
