1. WHAT ARE LLM EVALUATIONS?
======================================================================

Q. What are LLM Evaluations?

Answer:

LLM Evaluations are systematic, repeatable tests used to judge
an LLM or LLM-powered application against clearly defined criteria.

Purpose:

- Measure quality
- Measure safety
- Measure reliability
- Decide production readiness

---------------------------------------------------------------------

Q. Why can't we use Vibe Testing?

Answer:

Vibe Testing means asking a few questions and deciding
subjectively whether the system works.

Problems:

- Subjective
- Not repeatable
- Not scalable
- Not production ready

======================================================================
2. MODEL EVALUATION vs APPLICATION EVALUATION
======================================================================

Q. Difference between Model Evaluation and Application Evaluation?

Answer:

Model Evaluation:
Evaluates the LLM itself.

Examples:
- Reasoning
- Coding
- Mathematics
- Tool Usage

Application Evaluation:
Evaluates the complete AI system.

Examples:
- RAG
- Chatbots
- Agents
- Safety
- Latency
- Cost

Interview One-Liner:

Model Evaluation measures model capability.
Application Evaluation measures system capability.

======================================================================
3. APPLICATION EVALUATION WORKFLOW
======================================================================

Q. Explain Application Evaluation Workflow.

Answer:

1. Define Task
2. Define Success Criteria
3. Create Golden Dataset
4. Choose Evaluation Method
5. Run Application
6. Measure Results
7. Analyze Failures
8. Improve System
9. Re-evaluate
10. Deploy
11. Monitor Production
12. Add Failures to Golden Dataset

Interview Tip:

Evaluation is a continuous process, not a one-time process.

======================================================================
4. GOLDEN DATASET
======================================================================

Q. What is a Golden Dataset?

Answer:

A manually curated dataset used for evaluation.

Contains:

Input
+
Expected Output

Purpose:

Acts as the ground truth for evaluation.

---------------------------------------------------------------------

Q. Why is Golden Dataset important?

Answer:

Without a Golden Dataset:

- Recall cannot be measured
- Precision cannot be measured
- Correctness cannot be measured
- Regression Testing is difficult

======================================================================
5. EVALUATION METHODS
======================================================================

Q. What are the three Evaluation Methods?

Answer:

1. Programmatic Evaluation
2. Human Evaluation
3. LLM-as-a-Judge

---------------------------------------------------------------------

Q. When should Programmatic Evaluation be used?

Answer:

When expected output is structured.

Examples:

- Recall
- Precision
- Classification Accuracy

Advantages:

- Fast
- Cheap
- Scalable

---------------------------------------------------------------------

Q. When should Human Evaluation be used?

Answer:

For subjective tasks.

Examples:

- Helpfulness
- Tone
- User Experience

Advantages:

- Most reliable

Disadvantages:

- Expensive
- Slow

---------------------------------------------------------------------

Q. What is LLM-as-a-Judge?

Answer:

An LLM evaluates outputs generated by another LLM.

Used when:

- Outputs are long
- Semantic judgement is required
- Programmatic evaluation is difficult

7. RETRIEVER EVALUATION
======================================================================

Q. What metrics are used for Retriever Evaluation?

Answer:

1. Contextual Recall
2. Contextual Precision

---------------------------------------------------------------------

Q. What is Recall?

Answer:

Out of all relevant chunks,
how many were retrieved?

Formula:

Recall =
Relevant Retrieved
------------------
Total Relevant

---------------------------------------------------------------------

Q. What is Precision?

Answer:

Out of all retrieved chunks,
how many are actually useful?

Formula:

Precision =
Useful Retrieved
----------------
Total Retrieved

---------------------------------------------------------------------

Q. Difference between Recall and Precision?

Answer:

Recall:
Measures coverage.

Precision:
Measures usefulness.

Increasing K:

Recall ↑

Precision ↓

This is the Recall-Precision Tradeoff.

---------------------------------------------------------------------

Q. How can Retriever performance be improved?

Answer:

- Better Embeddings
- Better Chunking
- Increase K
- Add Reranker

======================================================================
8. GENERATOR EVALUATION
======================================================================

Q. What metrics are used for Generator Evaluation?

Answer:

1. Faithfulness
2. Answer Relevance

---------------------------------------------------------------------

Q. What is Faithfulness?

Answer:

Measures whether the answer is generated
from the provided context.

Interview One-Liner:

Faithfulness checks grounding.

---------------------------------------------------------------------

Q. What is Answer Relevance?

Answer:

Measures whether the answer actually answers
the user's question.

---------------------------------------------------------------------

Q. Difference between Faithfulness and Correctness?

Answer:

Faithfulness:
Answer comes from context.

Correctness:
Answer is factually true.

Example:

Wrong Context
      ↓
Answer uses context exactly

Faithful = YES
Correct = NO

Most Important Interview Question.

9. PIPELINE EVALUATION (RAG TRIAD)
======================================================================

Q. What is RAG Triad?

Answer:

The most important Pipeline Evaluation framework.

Three Metrics:

1. Context Relevance
2. Faithfulness
3. Answer Relevance

---------------------------------------------------------------------

Q. What does Context Relevance measure?

Answer:

Question ↔ Context

Checks:

Did Retriever fetch useful context?

---------------------------------------------------------------------

Q. What does Faithfulness measure?

Answer:

Context ↔ Answer

Checks:

Did Generator remain grounded in context?

---------------------------------------------------------------------

Q. What does Answer Relevance measure?

Answer:

Question ↔ Answer

Checks:

Did answer solve the user's question?

10. APPLICATION EVALUATION
======================================================================

Q. What metrics are evaluated at Application Level?

Answer:

1. Correctness
2. Completeness
3. Style

---------------------------------------------------------------------

Q. What is Correctness?

Answer:

Checks whether answer is factually correct
according to the real world.

---------------------------------------------------------------------

Q. What is Completeness?

Answer:

Checks whether answer covers
all parts of the question.

---------------------------------------------------------------------

Q. What is Style Evaluation?

Answer:

Checks whether responses follow
the desired communication style.

Example:

CampusX Style

- Simple explanations
- Conversational tone
- Beginner-friendly

11. G-EVAL
======================================================================

Q. What is G-Eval?

Answer:

G-Eval is an advanced LLM-as-a-Judge framework
that improves evaluation reliability.

---------------------------------------------------------------------

Q. Why was G-Eval introduced?

Answer:

Basic LLM-as-a-Judge suffers from:

- Score Variance
- Inconsistent Judgements

---------------------------------------------------------------------

Q. What are the two core innovations of G-Eval?

Answer:

1. Criteria → Evaluation Steps
2. Probability Weighted Scoring

This is the MOST IMPORTANT G-Eval question.

---------------------------------------------------------------------

Q. What is Criteria → Evaluation Steps?

Answer:

High-level criteria are converted into
detailed evaluation instructions.

Result:

More reliable evaluation.

---------------------------------------------------------------------

Q. What is Probability Weighted Scoring?

Answer:

Instead of directly returning score 8,

G-Eval uses probability distribution.

Example:

8 → 70%
7 → 20%
9 → 5%

Weighted Score:

7.84

instead of 8

Result:

More stable scores.

12. SAFETY EVALUATION
======================================================================

Q. What is LLM Safety?

Answer:

Ensuring an LLM application behaves safely
and does not cause harmful outcomes.

---------------------------------------------------------------------

Q. What three safety metrics were evaluated?

Answer:

1. Toxicity
2. Leakage
3. Scope Adherence

---------------------------------------------------------------------

Q. What is Toxicity?

Answer:

Generation of:

- Insults
- Abuse
- Hate Speech
- Threats

Lower score is better.

---------------------------------------------------------------------

Q. What is Leakage?

Answer:

Disclosure of:

- System Prompts
- PII
- Course Content
- Internal Instructions

---------------------------------------------------------------------

Q. What is Scope Adherence?

Answer:

Measures whether assistant stays inside
its intended role.

Example:

LLM Evaluations Tutor

Should answer:
LLM Evaluation Questions

Should reject:
Travel Planning

13. GUARDRAILS
======================================================================

Q. What are Guardrails?

Answer:

Controls used to prevent, detect,
or limit unsafe behavior.

---------------------------------------------------------------------

Q. Types of Guardrails?

Answer:

1. Prompt Guardrail
2. Input Guardrail
3. Output Guardrail
4. Retrieval Guardrail
5. Tool Guardrail

---------------------------------------------------------------------

Q. Difference between Prompt Guardrail and Output Guardrail?

Answer:

Prompt Guardrail:

Prevention

Example:

"Do not reveal PII"

Output Guardrail:

Enforcement

Response is checked before reaching user.

Production systems use both.

14. OPERATIONAL EVALUATION
======================================================================

Q. What are Operational Evaluations?

Answer:

Measure production readiness.

Focus:

- Speed
- Cost
- Reliability

---------------------------------------------------------------------

Q. Three major Operational Metrics?

Answer:

1. Latency
2. Cost
3. Reliability

---------------------------------------------------------------------

Q. What is Latency?

Answer:

Time taken to generate response.

---------------------------------------------------------------------

Q. Difference between P50, P95 and P99?

Answer:

P50:
50% requests complete within this time.

P95:
95% requests complete within this time.

P99:
99% requests complete within this time.

P95 is commonly discussed in interviews.

---------------------------------------------------------------------

Q. What is TTFT?

Answer:

Time To First Token.

Measures how long user waits before
seeing the first token.

---------------------------------------------------------------------

Q. Difference between Latency and Throughput?

Answer:

Latency:
Time for one request.

Throughput:
Requests processed per unit time.

---------------------------------------------------------------------

Q. What is Reliability?

Answer:

Ability to serve requests successfully.

Metrics:

- Success Rate
- Error Rate
- Timeout Rate
- Retry Rate

15. REGRESSION TESTING
======================================================================

Q. What is Regression Testing?

Answer:

Regression Testing ensures that a change
does not make the system worse.

---------------------------------------------------------------------

Q. Why is Regression Testing important?

Answer:

Improving one metric may degrade others.

Example:

Recall ↑

But

Precision ↓
Latency ↑

Therefore the entire evaluation suite
must be rerun.

---------------------------------------------------------------------

Q. What is baseline.json?

Answer:

Stores accepted evaluation results
before changes.

---------------------------------------------------------------------

Q. What is candidate.json?

Answer:

Stores evaluation results
after changes.

---------------------------------------------------------------------

Q. What is the Noise Problem?

Answer:

LLM-based evaluations are probabilistic.

Same evaluation can produce different scores
even without any code changes.

---------------------------------------------------------------------

Q. What is Noise Threshold?

Answer:

Defines acceptable score variation.

Usually:

Noise Threshold
=
2 × Standard Deviation

---------------------------------------------------------------------

Q. What is a Metric Registry?

Answer:

Stores:

1. Metric Direction
2. Noise Threshold

Used during baseline vs candidate comparison.
